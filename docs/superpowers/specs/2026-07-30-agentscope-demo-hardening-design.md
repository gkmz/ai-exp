# AgentScope 狼人杀 Demo 完整修复设计

## 目标

修复角色提示、目标校验、投票结算、配置启动、默认角色可达性、守护者能力、异常恢复、最大轮数结算、工程结构、测试和文档问题，并保持公开/私密消息语义清晰。

## 已确认玩法

- CLI 支持 `--players 6|8|9`，默认 8 人。
- 白天平票或全员弃票时无人出局，直接进入下一夜。
- 九人局完整实现守护者：可以守自己，不能连续两晚守同一人；守护抵挡狼刀，不抵挡女巫毒药。
- 被守护玩家不会作为当晚狼刀受害者告知女巫，避免守护和解药重复结算。
- 预言家不能查验自己，狼人不能击杀狼人，白天玩家不能投自己。

## 架构拆分

- `main.py`：只负责 CLI 入口和退出码。
- `config.py`：解析 CLI、加载环境变量并统一校验。
- `game.py`：保存游戏状态、创建玩家、消息投递、重试和主循环。
- `night_phases.py`：狼人、守护者、预言家和女巫阶段。
- `day_phases.py`：白天发言、投票、猎人遗言和开枪。
- `output.py`：所有动态 Pydantic 结构化输出模型。
- `util.py`：纯规则函数，包括投票和胜负判断。

## 可靠性

- Agent 调用统一经过有限次数重试；单个阶段失败按该阶段降级，不直接终止整局。
- 缺少任意模型环境变量时启动失败并返回非零退出码。
- 达到最大轮数时公开宣布平局。
- 角色映射缺失时抛出明确错误，不再默认当作村民。
