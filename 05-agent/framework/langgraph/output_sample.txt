### 2. Cursor 推出 Self-Hosted Machines

Cursor 发布 **Self-Hosted Machines**，允许云端智能体把工具执行迁移到企业自有网络中的机器上。

其基本架构是：

- 智能体循环、推理和规划仍由 Cursor 云端完成；
- 企业内部机器负责执行命令和工具调用；
- Worker 通过出站 HTTPS 与云端通信；
- Cursor 不主动连接企业内网。

这类设计可以帮助企业：

- 访问内网代码仓库；
- 使用本地数据库和内部工具；
- 减少源码和数据直接上传到云端；
- 满足部分合规和网络隔离要求。

但需要重点审查：

- 云端是否能下发任意命令；
- Worker 的身份认证和密钥管理；
- 命令执行白名单；
- 日志保存位置；
- 是否支持网络隔离和人工审批。

## 七、从这些新闻可以看出的行业趋势

综合来看，今天的 AI 行业有五个明显方向：

### 1. 竞争重点从“聊天能力”转向“执行能力”

厂商越来越重视 AI 能否：

- 使用工具；
- 操作电脑；
- 修改代码；
- 调用 API；
- 执行长周期任务；
- 在企业内网中完成工作。

### 2. 编程仍是最主要的商业化入口

Muse Spark、Claude Code、Cursor Composer、Qwen Code Arena 等消息都围绕代码能力展开。原因是编程任务：

- 容易评测；
- 容易量化生产力；
- 能直接节省人力成本；
- 更容易嵌入企业工作流。

### 3. 国产模型开始同时争夺性能、价格和生态

国内厂商不仅竞争模型能力，也在竞争：

- API 价格；
- 开源权重；
- 电商订阅；
- 企业部署；
- 多模态能力；
- 国内开发者生态。

### 4. AI 基础设施并购加速

如果 Hugging Face 收购消息最终属实，将说明 GPU 厂商不再只卖芯片，而是向：

- 模型社区；
- 开发工具；
- 模型分发；
- 推理服务；
- 数据和应用生态

进一步延伸。

### 5. 高能力模型带来的安全风险同步上升

当模型能够自动操作电脑、编写代码、发现漏洞或访问企业内网时，安全边界会变得更加重要。企业在部署 Agent 时，
应优先建立：

- 权限隔离；
- 沙箱环境；
- 命令白名单；
- 人工审批；
- 数据脱敏；
- 全链路审计；
- 可回滚机制。
