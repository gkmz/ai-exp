# 电子书 PDF 导出 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 CAMEL 五章协作正文完成后自动生成可阅读的中文 A5 PDF，并在内容不完整时拒绝生成残缺产物。

**Architecture:** 将章节解析、完整性校验和 ReportLab 排版放入独立的 `ebook.py`。主脚本只负责调用 CAMEL、收集每轮响应和触发导出；测试使用标准库 `unittest`，不依赖真实模型调用。

**Tech Stack:** Python 3.12+, CAMEL, ReportLab, `unittest`, macOS/Linux 系统中文字体。

## Global Constraints

- 每段关键代码都有明确的中文注释。
- 公开方法都有明确的文档注释。
- 后端主要使用 Go（本 demo 已是 Python，保持现有技术栈）。
- 不从历史 `output.txt` 自动恢复或解析电子书。
- 不引入需要额外安装 TeX 或浏览器的 PDF 生成链路。
- 默认输出 `output/pdf/拖延心理学.pdf`。

import unittest

from ebook import IncompleteEbookError, extract_chapter, validate_chapters


class ChapterExtractionTests(unittest.TestCase):
    def test_extracts_one_markdown_chapter_heading(self):
        result = extract_chapter("**第一章：拖延的大脑**\n\n正文内容")
        self.assertEqual(result, (1, "## 第一章：拖延的大脑\n\n正文内容"))

    def test_ignores_outline_with_multiple_chapters(self):
        result = extract_chapter("**第一章：A**\n**第二章：B**\n大纲")
        self.assertIsNone(result)

    def test_validate_reports_missing_chapters(self):
        with self.assertRaisesRegex(IncompleteEbookError, "缺少章节：2、4"):
            validate_chapters({1: "一", 3: "三", 5: "五"})


if __name__ == "__main__":
    unittest.main()
```

import tempfile
from pathlib import Path

from ebook import build_pdf


class PdfGenerationTests(unittest.TestCase):
    def test_build_pdf_writes_a_pdf_for_five_chapters(self):
        chapters = {index: f"## 第{index}章：测试\n\n中文正文。" for index in range(1, 6)}
        with tempfile.TemporaryDirectory() as temp_dir:
            output = build_pdf(chapters, Path(temp_dir) / "book.pdf")
            self.assertEqual(output.read_bytes()[:5], b"%PDF-")
            self.assertGreater(output.stat().st_size, 1000)
```
